# Glossary

Термины предметной области

- Запись - единица данных пользователя в таблице tasks: задача, встреча или напоминание. В API обозначается как event.
- Задача (task) - тип записи с необязательным точным временем: может иметь только срок. Статусы: active, in_progress, completed.
- Встреча (meeting) - тип записи с датой и точным временем, проверяется на конфликты и создаётся в Google Calendar. Статусы: active, completed.
- Напоминание (reminder) - тип записи с датой и точным временем. Статусы: active, completed. Отличается от уведомления: напоминание - запись, уведомление - сообщение о её моменте.
- task_id - идентификатор диалога, а не записи. Живёт в Redis 24 часа и возвращается клиенту для продолжения.
- event.id - идентификатор строки tasks. В уведомлениях поле task_id означает именно его, не диалог.
- Диалог - последовательность запросов, связанных одним task_id: уточнения, выбор кандидатов, продолжение темы.
- Черновик - незавершённое намерение создать запись, хранящееся в контексте диалога до уточнения данных.
- Кандидаты - пронумерованный список найденных записей перед удалением или изменением. Номера стабильны внутри диалога.
- changes - предлагаемые значения полей при изменении; применяются только к выбранным кандидатам.
- Интент - класс намерения запроса: create_event, list_events, search_events, on_delete, on_update, chat. Передаётся в заголовке X-Task-Intent.
- needs_clarification - статус ответа: ассистенту нужны данные, черновик сохранён, база не изменена.
- Фаза - шаг двухфазного интента: find_candidates (поиск) и delete_confirmed или update_confirmed (действие по выбору).
- STT - распознавание речи. Реализовано локально: sherpa-onnx
- TTS - синтез речи. Не реализован, ответы текстовые.
- LLM - языковая модель: разбор запроса (/api/job) и формулировка ответа (/api/respond). Провайдер - Cloud.ru Foundation Models (GigaChat).
- E5 - модель эмбеддингов multilingual-e5-small: 384 измерения, локальный CPU-инференс.
- model_version - идентификатор версии эмбеддингов (хеш манифеста). Сравнивать можно только векторы одной версии.
- pgvector - расширение PostgreSQL для векторного поиска; таблица task_embeddings.
- Problem - формат ошибок API по RFC 9457 (application/problem+json) с полем code.
- Уведомление - запись в таблице notifications о моменте события. Виды: task_due, reminder_due, meeting_start.
- Опережение - заранее запланированный момент уведомления: за 72 часа, 24 часа, 3 часа или 10 минут до события.
- ack - подтверждение клиента о получении уведомления. Идемпотентно.
- OAuth state - одноразовый ключ защиты OAuth-потока Google, живёт 10 минут.
